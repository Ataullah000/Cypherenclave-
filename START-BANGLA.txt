  Cypherenclave v1.0 — শুরু করার গাইড
========================================

১) Node.js ইনস্টল করো (একবারই লাগবে)
   https://nodejs.org  →  LTS বাটন → Install
   ইনস্টল শেষে কম্পিউটার রিস্টার্ট করতে পারো

২) এই ফোল্ডার খোলো (app ফোল্ডার)

৩) ফোল্ডারের ভিতরে টার্মিনাল খোলো
   Windows: ফোল্ডারে Shift + Right-click → "Open in Terminal"
   Mac: ফোল্ডারে Right-click → "New Terminal at Folder"

৪) টার্মিনালে লিখো (কপি-পেস্ট করো):

   npm install

   শেষ হলে:

   npm run dev

৫) ব্রাউজারে যাও:
   http://localhost:3000
